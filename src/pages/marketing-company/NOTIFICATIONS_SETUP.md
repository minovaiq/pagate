# تشغيل نظام التنبيهات

## 1. قاعدة البيانات
نفّذ الملف التالي مرة واحدة داخل Supabase SQL Editor:

`marketing_notifications.sql`

هذا الملف ينشئ جدولاً جديداً فقط ولا يغيّر الجداول الحالية.

## 2. تفعيل التحديث المباشر
من Supabase افتح:

Database → Replication → Supabase Realtime

ثم فعّل جدول:

`marketing_notifications`

بدون تفعيل Realtime سيظل مركز التنبيهات يعمل عند إعادة الفتح، لكن التنبيه لن يظهر فوراً من جهاز آخر.

## 3. إشعارات الهاتف
زر **إشعارات الهاتف** يطلب إذن إشعارات المتصفح.

هذه النسخة تعرض إشعار الهاتف عندما يكون النظام مفتوحاً أو مثبتاً كتطبيق ويعمل في الخلفية المسموح بها من المتصفح.

حتى تصل الإشعارات والهاتف مغلق أو التطبيق متوقف بالكامل، يلزم ربط Firebase Cloud Messaging بمفاتيح مشروعك وإضافة Service Worker وEdge Function. لم توضع مفاتيح وهمية داخل المشروع.
